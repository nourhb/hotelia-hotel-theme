== Description ==

Hotelia is a luxurious Full Site Editing theme crafted for hotels and boutique stays. Deep navy and champagne gold design, booking hero, rooms and suites showcase, amenities grid, gallery, dining teaser, testimonials and reservation CTAs — everything a refined hotel needs to welcome guests online.

A clean, modern Full Site Editing (block) theme built with theme.json. Includes multiple page templates (Rooms, About, Gallery, Contact), curated block patterns, and a style variation. Translation-ready and accessibility-conscious.
