# Hotelia — Luxury Hotel WordPress Theme

A luxurious Full Site Editing (FSE) block theme crafted for hotels and boutique stays, by **Nour El Houda Bouajila**.

## Design

Deep navy ink + champagne gold, Playfair Display serif headings with Inter body text, generous whitespace, and a prominent "Book Your Stay" call to action.

## Templates (12)

- `front-page.html` — booking hero, rooms showcase, amenities, gallery, dining, testimonials, booking CTA
- `page-rooms.html` — rooms grid with rates table and FAQ
- `page-about.html` — story, animated stats, gallery
- `page-gallery.html` — full photo gallery
- `page-contact.html` — contact info, reservation request form layout, FAQ
- `page.html`, `page-wide.html`, `single.html`, `archive.html`, `search.html`, `index.html`, `404.html`

## Block patterns (11)

hero-booking, rooms-showcase, amenities-grid, gallery-masonry, testimonials, pricing-rooms, faq, cta-booking, contact-info, about-story, dining-teaser

## Style variations

- Default (Ink & Gold)
- Ivory (light luxury)

## Notes

- All photography is bundled locally in `assets/images/` (Unsplash License).
- Fonts (Inter + Playfair Display) are bundled as WOFF2 (SIL OFL).
- Translation-ready (`languages/`, text domain `hotelia`).
